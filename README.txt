EGG TIMER
=========

A small desktop egg timer application developed with C++ and raylib.

Egg Timer allows you to choose between hard-boiled and soft-boiled eggs
and provides recommended cooking times for both options.

FEATURES
--------

- Hard-Boiled and Soft-Boiled egg selection
- Recommended cooking times
- Start / Pause timer
- Reset timer
- Mouse navigation
- Keyboard controls
- Animated interface elements
- Custom pixel-art buttons
- Button sound effects
- Background music


CONTROLS
--------

Mouse:
- Click the Startscreen to continue
- Click an egg to select Hard-Boiled or Soft-Boiled
- Start / Stop Button: Start or pause the timer
- Reset Button: Reset the timer
- Home Button: Return to the Startscreen

Keyboard:
- Enter: Start / Confirm selection
- Left / Right Arrow: Select egg
- Space: Start / Pause timer
- R: Reset timer
- H: Return to Startscreen
