# Egg Timer

A small desktop application developed with **C++** and **raylib** for practice.

## Features
- Animated Startscreen
- Egg selection (Hard-Boiled / Soft-Boiled)
- Animated selection arrow
- Multiple States
- Stopwatch
- Return to Startscreen
- Windows release build with custom application icon

## Controls
| Key | Action |
|------|--------|
| Enter | Start / Confirm selection |
| ← → | Select egg |
| Space | Start / Pause stopwatch |
| R | Reset stopwatch |
| H | Return to Startscreen |

## What I learned
- State management
- Separating code into `.h` / `.cpp`
- Texture loading and unloading
- Sprite sheet animations
- Drawing with `DrawTextureEx` and `DrawTexturePro`
- Time handling with `GetFrameTime()`
- Basic Git workflow
- Creating Windows release build
